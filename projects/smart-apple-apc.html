3인 팀 프로젝트 · 로보틱스 시뮬레이션

Smart APC · 사과 선별·물류 자동화

카메라로 사과 등급을 판정하고, AMR(자율주행 이동로봇)이 등급별 적재 구역으로 운반하는 농산물산지유통센터(APC)를 ROS 2와 Gazebo 시뮬레이션으로 구현합니다. 저는 AMR 주행·물류 파트를 맡고 있습니다.

진행 중 ROS 2 AMR 물류 Gazebo 시뮬레이션

01 / BACKGROUND

문제 배경

농산물산지유통센터(APC)는 수확한 사과를 크기와 품질에 따라 선별하고 등급별로 모아 출하하는 곳입니다. 선별과 운반 모두 사람 손이 많이 가는 작업이라, 농촌 인력난이 심해질수록 이 과정을 자동화할 필요가 커지고 있습니다.

이 프로젝트는 선별(비전)과 운반(이동 로봇)을 하나의 흐름으로 연결하는 데 초점을 둡니다. 실제 설비 없이도 로봇 소프트웨어 구조를 그대로 검증할 수 있도록, 순수 Python 시뮬레이션 대신 실제 로봇에서 쓰는 ROS 2와 Gazebo를 택했습니다.

02 / SYSTEM

시스템 흐름

  1. ① 컨베이어 · 카메라

    Gazebo 월드에서 사과가 주기적으로 스폰되어 컨베이어를 따라 이동하고, 카메라 영상이 ROS 2 토픽으로 전달됩니다.

  2. ② 등급 판정

    YOLO 기반 비전 노드가 사과를 특·상·보통·비상품 4등급으로 판정하고 지름과 결함 비율을 함께 발행합니다.

  3. ③ 운반 작업 관리

    AMR 노드가 판정 결과를 받아 등급별 적재 구역을 배정하고, 운반 작업을 큐에 쌓아 순서대로 처리합니다.

  4. ④ 주행 · 하역

    Nav2로 배정된 구역까지 자율주행한 뒤 하역하고, 로봇 상태(대기·적재·이동·하역)를 실시간으로 발행합니다.

세 파트는 공통 메시지(AppleGrade, AmrStatus)와 토픽 규약으로만 연결됩니다. 모든 노드에 mock 모드가 있어서, 다른 파트가 완성되기 전에도 각자 가짜 입력으로 개발하고 테스트할 수 있습니다.

03 / MY ROLE

담당 파트: AMR 주행·물류

3인 팀에서 비전 / AMR / 시뮬레이션·통합으로 나눈 가운데 AMR 주행·물류 패키지(apc_amr)를 맡았습니다. 비전 노드가 내보낸 등급 판정을 받아 사과가 실제로 알맞은 구역에 도착하게 만드는 부분입니다.

  • 등급 → 구역 배정. 특·상·보통·비상품을 각각 A·B·C·R 구역에 대응시키고, 구역 좌표는 설정 파일(zones.yaml)로 관리해 월드가 바뀌어도 코드를 고치지 않게 합니다.
  • Nav2 주행. NavigateToPose 액션 클라이언트를 구현해 배정된 구역 좌표로 로봇을 보내고, 도착 결과를 받아 하역 단계로 넘깁니다.
  • 적재·하역 시퀀스. 적재 → 이동 → 하역 → 대기로 이어지는 상태 전이를 정의하고, 각 상태를 모니터링 토픽으로 발행합니다.
  • 작업 큐 정책. 기본은 선입선출(FIFO)로 처리하고, 필요하면 등급 우선순위 방식을 추가해 비교합니다.
  • 운반 성능 측정. 작업당 소요 시간과 처리량을 지표로 정리합니다.

개발 환경을 정할 때 Ubuntu 26.04 LTS + ROS 2 Lyrical + Gazebo Jetty 조합을 제안해 팀 표준으로 채택되었습니다. 2031년까지 지원되는 최신 LTS이고 Nav2 바이너리가 배포되는 것을 확인한 뒤 제안했습니다.

04 / PROGRESS

현재 진행 상황

팀 저장소에 ROS 2 패키지 구조, 공통 메시지, 파트별 mock 노드가 마련되어 있습니다. AMR 노드는 mock 모드에서 등급 수신 → 구역 배정 → FIFO 큐 → 상태 발행까지 동작하고, 지금은 이 뼈대에 Nav2 주행을 연결하기 위한 환경 구축과 인터페이스 확정 단계에 있습니다.

  • 진행 중: 팀 공통 환경 구축, 메시지·등급 기준 합의
  • 다음: Nav2 튜토리얼 실행 → APC 월드 맵 생성 → NavigateToPose 액션 클라이언트 구현
  • 이후: 적재·하역 시퀀스, 큐 정책 비교, 운반 지표 정리

팀 전체로는 컨베이어 이동·사과 스폰 월드와 카메라 브리지가 완성되었고, 비전 파트는 AI Hub 사과 품질 이미지로 YOLO11s 베이스라인 학습을 마쳤습니다.
